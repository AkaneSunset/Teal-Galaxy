# Arena maps (Blender blockouts)

Nineteen arena maps: every map the research report *Arena Shooter Game Modes: What Works, Why, and What
Teal Galaxy Should Build* describes. That's the six Teal Galaxy concepts (section 10.4, table 14, below), the four map
archetypes (figures 7, 8, 10 and 12) and nine per-mode map types (table 9). [MAP_INVENTORY.md](MAP_INVENTORY.md)
lists them all, with the report's layout data for each. They're greybox blockouts: the
layout, heights, routes and every gameplay spot, ready to playtest and then dress with art. Every map is
generated by [`tools/blender/arena_maps.py`](../../tools/blender/arena_maps.py), so a layout change is a code
change you can review and rebuild.

| Map | Modes | What it is |
|---|---|---|
| **High Port Ring** | Sector Hold, Hardpoint, Slayer, Oddball | A ring corridor round a core atrium. Three zones 120° apart, so it plays as 2 or 3 teams. The balcony round the atrium is the high ground, reached by ramps in the three spokes. |
| **Carrier Dock Pads** | Slayer, CTF, Hardpoint | Two landed carriers face each other across a Carrier Dock. Container rows split the dock into a middle lane and two side lanes. Each carrier's hold is a base with the flag, a mezzanine perch and crew doors. |
| **Hangar and Flight Deck** | Hardpoint, Slayer | Close quarters in the hangar, long sightlines on the flight deck above. Two ramps and two lifts connect them. The hill rotates round the hangar floor, both lifts, the catapult and the observation tower. |
| **Outpost Vault** | Core Breach, One Flag "Data Core" | Attackers cross the outpost's 12x12 surface grid and go down three shafts (the middle one has a drop). Two charge points on the level below. Defenders start in the vault with the data core. |
| **Carrier Boarding** | Boarding Action | Linear: take the hangar (or come in over the flight deck), push the breach charge round the reactor in the power room, then storm the bridge. Each side has a spawn set for each section. |
| **Besieged Outpost** | Coma Firefight | Hold the outpost core while Coma bots drop in at six zones outside the walls. There are four turrets on the walls, with resupply crates in the open below them. |

The report says every faction should get its own look for each map (Compact armour plate, Ashen dark hulls,
Luminar clean lines) with the same geometry, so ranked play stays fair. These blockouts are that shared
geometry.

Also built from the archetypes and table 9: **Twin Bastions** (three-lane CTF/Slayer), **Spindle Yard**
(rotating hill), **Three Pylons** (static three zones), **Supply Line** (Payload, Escort, Hybrid, Rush,
Breakthrough), **Lattice** (Onslaught/Warfare node chain), **Foundry Spire** (DM/FFA/Duel), **Longwatch**
(Instagib), **Crossfire Box** (Gun Game), **Nest Loop** (Oddball), **Relay Sites** (Search and Destroy),
**Tug Line** (Push), **Goal Field** (Bombing Run) and **Attrition Front** (Attrition).

## Planet terrain

The eight maps that are fought on a planet's surface are set in terrain built the way the game builds
its own planet ground (`game/terrain.gd` and `game/battle/battle_terrain.gd`). The ground is faceted and
uses the world's palette. There's gentle relief where the fighting happens, flattened under every
building, spawn and objective. Past the edge of play it rises into rolling high ground, ridged peaks,
mesas and a cliff or ledge on one side, with boulders scattered over it (and ice on frost worlds).
Where an arena wall stood, a steep bank now marks the edge of play.

| Map | World | Relief in play |
|---|---|---|
| Carrier Dock Pads | frost | flat (a built dock) |
| Outpost Vault | frost | flat (the outpost grid) |
| Besieged Outpost | ash | 0.8 m |
| Twin Bastions | moss | 0.6 m |
| Supply Line | dust | 1.6 m |
| Lattice | moss | 3.5 m |
| Relay Sites | dust | 0.4 m |
| Attrition Front | ash | 1.8 m |

The station and carrier interiors (High Port Ring, Hangar and Flight Deck, Carrier Boarding) and the
enclosed arenas stay as they are. The world and relief for each map are in `OUTDOOR` in the script.
Any of these maps can use any world (`frost`, `dust`, `moss`, `ash`), for example to match the planet a
match is fought on. The terrain is in its own *Terrain* collection and goes into the .glb with its
vertex colours.

## Files per map

- `<id>.blend`: the editable Blender file. The collections are *Geometry*, *Markers*, *Labels* and, where
  a map has them, cutaway layers (*Roofs*, *Deck*, *Surface*, *Tower Roof*).
- `<id>.glb`: for Godot. It has the geometry and markers but no labels. Each marker's game data is in
  its glTF extras, so Godot puts it in the node's metadata.
- `<id>.json`: just the markers (spawns, zones, hills, flags, charges and so on), with positions.
- `<id>_perspective.png` and plan views (`_plan`, or `_hangar` / `_deck`, `_lower` / `_surface`).

## Markers

Every marker object has a `kind` property. The kinds are `spawn` (with `team` and `set`), `zone`, `hill`
(with `order`, rotation order), `flag`, `ball`, `charge`, `core`, `checkpoint`, `path` (the breach charge's
route, in `order`), `pickup` (with `item`), `resupply`, `drop_zone`, `lift` and `objective`.

Units are metres. Blender is Z up (x east, y north). The .glb is Y up, as Godot expects:
Godot (x, y, z) = Blender (x, z, −y).

## Rebuilding

```sh
pip install bpy==5.0.1        # with Python 3.11; or use a Blender 5 install with -b -P
python3.11 tools/blender/arena_maps.py --out art/arena_maps                 # all 19
python3.11 tools/blender/arena_maps.py --out art/arena_maps --only vault    # one: see MAPS in the script
python3.11 tools/blender/arena_maps.py --out art/arena_maps --no-render     # skip the previews
```
